# BOOSTCAD

RIKCADのPLNをブラウザー内で直接読み、3D表示・長さ・高低差を確認する試作ツールです。利用者側にNode.jsやRIKCADのインストールは不要です。

サイトを開いて「PLNを開く」でファイルを選択するか、表示領域へドロップしてください。「デモを開く」では自作の操作確認用形状を表示します。PLNはWeb Worker内で処理し、サーバーへ送信しません。外部ライブラリCDNや解析サービスも使いません。

## 操作

- 2点計測：形状上の2点をクリック。途中は光る線で追従し、複数の計測を保持します。頂点へ近づくと点線が反応します。
- 高低差：最初の点を基準に、次の点から順に標高差を表示します。基準点との点線は表示しません。
- 平面図：真上からのオルソ投影へ切り替え、XYの平面距離を測ります。このモードで確定した計測は3Dへ戻しても平面距離を保持します。
- 1点戻す、Escで途中の点を取り消し、クリアで全計測を一括削除できます。単位はmm/mから選択できます。

## 表示する形状

地形上面、スラブの基本形状、モーフ、直線壁と矩形窓開口に対応します。窓はPLNに保存された幅・高さ・位置から作る寸法面です。**窓枠やガラスの形状ではありません。メーカー部品、植栽、屋根、扉は表示しません。** メーカー部品名・件数は読み込んだプランから未表示一覧に出します。

RIKCADの部品ライブラリを配布・参照しません。部品を仮の形状へ置き換えることもありません。デモは顧客データを使用していません。

## 計測の範囲

保存されている頂点・基本寸法を使用する実験的なリーダーです。すべてのPLN形式への対応やRIKCAD画面との一致を保証するものではありません。

壁の屋根による上端トリム、傾斜・曲線壁、スラブの接合・ソリッド演算、地形の側面・底面などは未対応です。曲面は面分割した形状で計測します。フロアの絶対標高は未復元のため、異なるフロア間では高低差を測れません。元ファイル上限160 MiB、展開後上限256 MiBです。

## 開発・公開

開発時のみNode.js 22以降を使います。npm依存パッケージのインストールは不要です。

```sh
npm test
npm run build
npm run preview
```

プレビューは `http://127.0.0.1:4174/BOOSTCAD/` です。サイト配下のパスでも動く相対URLを使用しています。

GitHubで公開リポジトリ `BOOSTCAD` を作成し、このフォルダーの内容をmainブランチへpushします。Settings → Pages → Sourceで **GitHub Actions** を選択すると、付属のワークフローが検証後に `dist/` を公開します。通常の公開URLは `https://アカウント名.github.io/BOOSTCAD/` です。既存のツール一覧ページにはこのURLを登録できます。

公開対象はビルドスクリプトで指定するHTML/CSS/JSとライセンスのみです。顧客PLN・商用部品ライブラリをリポジトリへ追加しないでください。
